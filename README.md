# 用增归因数据看板

[在线演示](http://117.50.193.55/)

静态交互看板，支持分类下钻、日／周明细、统一日期筛选和 PV／UV 转化漏斗。

## 功能

- 数据覆盖 2026-07-01 至 2026-09-10，共 72 天；全页共用日期范围和日／周粒度。
- 最近 7 天、7 月 1—30 日、8 月、本月、全部日期快捷筛选。本月指快照的 2026 年 9 月。
- 注册归属 → 用增渠道 → 具体来源；点击分类联动趋势，点击数字查看明细。
- 自然周从周一开始，周标题可展开每天；首尾不足一周标注实际天数。
- 下方访问与转化报告同步展示 PV、UV、注册、实名和消费，支持漏斗下钻及 CSV 导出。
- UV 跨天、跨周去重；上下两部分的注册合计一致。
- 支持手机布局、固定列、横向滚动和外观调整。

## 数据口径

这是固定日期的模拟快照，不会随实际日期自动新增数据。每日记录、用户标识、跨周重合以及分类与来源拆分均为构造数据。附件四周的核心指标作为周基准：

| 日期范围 | 注册总量 | 实名量 | 消费量 | PV | UV |
| --- | ---: | ---: | ---: | ---: | ---: |
| 8.10—8.16 | 1,013 | 486 | 299 | 55,751 | 41,436 |
| 8.17—8.23 | 1,080 | 511 | 321 | 56,826 | 41,929 |
| 8.24—8.30 | 1,092 | 510 | 228 | 56,021 | 41,205 |
| 8.31—9.6 | 1,142 | 520 | 294 | 56,738 | 41,361 |

完整选择对应周时，以上数值与附件一致；日数据为模拟分配，其他日期亦为模拟。附件年份按 2026 年假设。实名、消费暂按人数模拟为注册用户的子集，不代表已核实的真实单位或同批用户转化口径。漏斗宽度按实际人数比例绘制；支持以访问 UV 为起点查看全流程，或以注册人数为起点放大后续转化。标签显示人数和占起点比例。

PV 按日求和；UV 按查询范围去重，不能直接累加每日或每周 UV；转化率按区间人数重新计算。附件的品牌、外拓、大使三类之和与注册总量存在差异，因此分类使用独立模拟拆分。

`mock-data.js` 保留早期分类与来源元数据。运行时 `unified-data.js` 重新生成日期和趋势；页面不使用旧的固定摘要值。

## 本地运行

无需构建，使用静态文件服务器：

```sh
python -m http.server 8765
```

访问 `http://127.0.0.1:8765/`。React、Babel、ECharts 和字体从公共 CDN 加载，需要联网。

## 部署产物

使用 Node.js 运行：

```sh
node package-preview.cjs
```

生成 `preview.html`，内嵌项目源码和样式，可直接打开，公共 CDN 依赖仍需联网。当前线上版本将该产物作为站点 `index.html`。也可直接部署源码静态目录。Nginx 示例位于 `deploy/nginx-growth-dashboard.conf`；替换前请备份旧首页。

## 验证

```sh
npm install
npx playwright install chromium
npm test
```

默认使用 Playwright Chromium；本机已有 Edge 时可设置环境变量 `BROWSER_CHANNEL=msedge`。测试输出位于忽略的 `test-output/`。

验证覆盖 72 天、20 项附件周基准、用户层级与 UV 去重、7 月 1—30 日上下联动、日周展开、注册合计、任意及错误日期、CSV 和手机宽度。测试线上站点：

```sh
node tests/check-unified.cjs http://117.50.193.55/
```

## 文件

- `app.jsx`：全局日期、趋势、分类明细与弹层。
- `unified-data.js`：72 天模拟数据、周基准、去重汇总。
- `unified-report.jsx`：同步日期的指标、漏斗、日报／周报。
- `styles.css`、`traffic.css`：样式。
- `mock-data.js`、`tweaks-panel.jsx`：基础数据与外观控件。
- `package-preview.cjs`：生成部署页面。
- `tests/check-unified.cjs`：浏览器和数据验证。
