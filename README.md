# 用增归因数据看板

一个支持四级注册归因、曲线联动和渠道展开的静态数据看板原型。

## 功能

- 全部注册量 → 注册归属 → 用增渠道 → 具体来源四级展开
- 点击名称切换对应趋势曲线
- 点击右侧下钻图标展开或收起下一级
- 支持 7 天、14 天和 30 天趋势切换
- 支持单条曲线显示与隐藏
- 自适应纵轴，避免大数值曲线遮盖小渠道趋势

## 本地运行

项目不需要构建，使用任意静态文件服务器即可：

```bash
python -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/`。

## 文件说明

- `index.html`：页面入口及依赖加载
- `app.jsx`：看板结构、图表及交互逻辑
- `mock-data.js`：演示数据与四级归因映射
- `styles.css`：页面样式
- `tweaks-panel.jsx`：样式调整面板
- `deploy/nginx-growth-dashboard.conf`：Nginx 静态部署示例
